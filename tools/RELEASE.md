# Выпуск релиза Astra DS — чек-лист

Каждый пункт — при каждом релизе, вручную. Сеть во время работы клиента для этого не используется
(номер сборки и версию браузера клиент сам не узнаёт и не скачивает).

## 1. Отпечаток клиента (src/net.c)
- [ ] `client_build_number` (сейчас **668923**) — текущий номер сборки веб-клиента Discord
      (виден в настоящем браузере: DevTools → любой запрос к API → заголовок `X-Super-Properties`, base64).
- [ ] Версия Chrome (сейчас **152**) — в строке User-Agent (`Chrome/152.0.0.0`) и в `browser_version`
      (`152.0.0.0`): текущая стабильная версия Chrome. Обе строки менять вместе.
- Версия Chrome должна совпадать с профилем impersonate в `src/login.c` (`chrome152`): менять вместе с библиотекой в `third_party/impcurl/`.

## 2. Версия
- [ ] `ASTRA_VERSION` в `src/mc.h` — строго больше прошлого релиза (иначе обновление его не увидит: отката нет).
- [ ] Тег релиза на GitHub `vX.Y.Z` — тот же номер.

## 3. Сборки (4 файла)
- [ ] Windows: `bash build.sh` → `astra-ds.exe`; `VIDEO=1 OUT=build-video bash build.sh` → `astra-ds-video.exe`.
- [ ] Linux: то же на Linux → `astra-ds`, `astra-ds-video`.
- [ ] Каждая: `--selftest` — 0 FAIL; `--version` показывает новую версию (Video — «Astra DS Video … (демонстрация экрана и камера)»).
- Обычная сборка не содержит кода видео (`src/streamtest.c` компилируется только при `VIDEO=1`).

## 4. Подпись (ключи — вне репозитория, `E:/projects/astra-ds-signing/`, зашифрованы паролем)
- [ ] Один раз, если ещё нет: `bash tools/protect_keys.sh` (пароль задаёт владелец; запасной ключ — на отдельный носитель).
- [ ] Для каждого из 4 файлов:
      `bash tools/sign_release.sh ФАЙЛ ПРОДУКТ ПЛАТФОРМА X.Y.Z`
      ПРОДУКТ: `astra-ds` | `astra-ds-video`; ПЛАТФОРМА: `win-x64` | `linux-x64`.
      Скрипт спросит пароль ключа и создаст `manifest-ПРОДУКТ-ПЛАТФОРМА.json` и `.json.sig`.
- [ ] Проверка встроенным ключом: `ST_UPD_MANIFEST=путь/manifest-….json astra-ds --selftest` — строка
      «манифест из sign_release.sh проходит встроенным ключом» — ok (для Video — сборкой Video).
